# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added / Añadido

- Phone menu, highlighted current section, skip link, visible focus and reduced motion. / Menú en el teléfono, sección actual resaltada, enlace para saltar al contenido, foco visible y movimiento reducido.
- Catalog search, saved products, purchase messages per product and club form with email validation. / Buscador del catálogo, productos guardados, mensaje de compra por producto y club con validación del correo.

### Changed / Cambiado

- It is described as a one-page website, not a landing page: it has a section menu and several goals. / Se describe como sitio web de una página, no como landing: tiene menú por secciones y varios objetivos.
- Display typeface for headings and copy written in the business's voice instead of describing the demo. / Tipografía de títulos propia y textos con la voz del negocio en lugar de describir la demo.
- Privacy policy: the fields only prepare the WhatsApp message; nothing is sent to a server. / Política de privacidad: los campos solo preparan el mensaje de WhatsApp; nada se envía a un servidor.

### Removed / Eliminado

- Unused `src/App.css`. / `src/App.css` sin uso.

- SEO, security and privacy standard: canonical, Open Graph/Twitter with image, JSON-LD, robots, sitemap, manifest, icons, 404, `security.txt`, strict CSP and HTTP headers, privacy policy and self-hosted fonts. / Estándar de SEO, seguridad y privacidad: canonical, Open Graph/Twitter con imagen, JSON-LD, robots, sitemap, manifest, iconos, 404, `security.txt`, CSP estricta y cabeceras HTTP, política de privacidad y tipografías autoalojadas.
- `src/estandar.test.jsx`: tests for the standard above and for Venezuelan Spanish (no voseo). / Pruebas del estándar anterior y del español venezolano (sin voseo).
- English README. / README en inglés.

- Community and quality files: license, code of conduct, contributing guide, security policy, issue and pull request templates, Dependabot and CI. / Archivos de comunidad y calidad: licencia, código de conducta, guía de contribución, política de seguridad, plantillas de issues y pull requests, Dependabot y CI.
